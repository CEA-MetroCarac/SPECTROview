# Internationalization (i18n) Standards

`SPECTROview` supports live-switchable GUI localization across five languages — **English** (`"en"`, default), **French** (`"fr"`, `Français`), **Simplified Chinese** (`"zh"`, `简体中文`, `zh_CN`), **German** (`"de"`, `Deutsch`, `de_DE`), and **Russian** (`"ru"`, `Русский`, `ru_RU`) — managed centrally by `spectroview.i18n` and `spectroview/resources/i18n/<lang>.json`. For multilingual MkDocs documentation synchronization across the same five languages, see [.agents/rules/documentation.md](documentation.md).

---

## 1. Mandatory Use of Centralized Translation Helpers

- Every user-facing string in `view/`, `viewmodel/`, `settings/ui/`, `ai_agent/`, and `main.py` **must** go through `spectroview.i18n`:
  - **Live-bound widgets** (menus, buttons, labels, checkboxes, group boxes, window/tab titles, placeholders, table headers, fixed comboboxes): use `bind_text`, `bind_plural_text`, `bind_tooltip`, `bind_placeholder`, `bind_title`, `bind_window_title`, `bind_tab_text`, `bind_header_labels`, `bind_combo_items`, or `on_language_changed(owner, callback)`.
  - **Transient/runtime messages & plots** (notifications, `QMessageBox`, `QInputDialog`, `QFileDialog`, status messages, axis labels, dynamic legends): use `tr(...)` and `tr_plural(...)`.
- **Never** scatter `if language == "fr": ... elif language == "zh": ...` conditionals across views or ViewModels.

---

## 2. Synchronous Catalog Updates (`fr.json`, `zh.json`, `de.json`, `ru.json`)

- Keep all non-default translation catalogs — `spectroview/resources/i18n/fr.json`, `zh.json`, `de.json`, and `ru.json` — updated in the **same commit** whenever adding or editing user-facing English strings (sorted JSON keys, UTF-8, `ensure_ascii=False`, 2-space indent).
- Preserve exact English source keys (e.g. `"Light Mode"`, `"Dark Mode"`, `"Logarithmic"`, `"Symlog"`).
- Write natural, accurate scientific and spectroscopy terminology in each language; keep format placeholders (`{name}`, `{count}`) identical across all catalogs, and provide language-appropriate plural forms (`1` form for `zh`, `2` forms for `fr`/`de`, `3` Slavic forms for `ru`).

---

## 3. Critical Rules & Pitfalls

1. **Canonical `Qt.UserRole` (`itemData`) on Translated `QComboBox` Widgets**:
   - Store canonical English/internal identifiers in `itemData` via `bind_combo_items(combo, [(label, canonical_key), ...])` (never `None` as sentinel `itemData` when display text differs from key — use `"default"`, `"None"`, or `""`).
   - Always read and restore selections with `combo_data_or_text(combo)` and `set_combo_by_data_or_text(combo, value)`, never `currentText()` or `setCurrentText()` on translated items.
2. **`tr_plural` Argument Contract**:
   - `tr_plural(singular, plural, count, *, ctx="", **kwargs)` automatically injects `"count": count` from positional arg #3. **Never** pass `count=...` again as a keyword argument (raises `TypeError: got multiple values for argument 'count'`).
3. **Escaped Literal Braces in Formatted Templates**:
   - When calling `tr("...{var}...", var=...)` with literal braces such as LaTeX math (e.g. `cm$^{-1}$`), double the literal braces as `cm$^{{-1}}$` in both Python source and all JSON catalogs.
4. **Live Re-translation Callbacks & Lifetime**:
   - `on_language_changed(owner, callback)` invokes `callback()` with **0 arguments** using a weak reference to `owner` — keep `owner` alive (typically `self`) and avoid creating orphan lambdas that capture strong cycles to destroyed widgets.
   - Never call `QLocale.setDefault(...)` globally (must keep `.` decimal separator in scientific spinboxes and text exports). Qt standard dialog buttons localize via `QTranslator` (`qtbase_fr.qm`, `qtbase_zh_CN.qm`, `qtbase_de.qm`, `qtbase_ru.qm`).

---

## 4. Non-Translatable Exclusions

Never translate:

- Python identifiers, module/class/function names, API parameters, or `MGraph` / `.spectra` / `.maps` schema keys.
- DataFrame column names, `PEAK_MODELS`, colormap names, Matplotlib `'Pan'` / `'Zoom'` mode strings, marker codes (`MARKERS`), file extensions (`PNG`, `CSV`, `WDF`), or wafer sizes (`300`, `200`).
- Physical units, operators, chemical/mathematical notation, scientific symbols (`x0`, `FWHM`, `α`, `q`, `tau`, `R²`), `CITATION_TEXT`, internal LLM prompt Markdown templates, or user-loaded filenames/sample labels.

---

## 5. Verification Gate

Before committing UI or ViewModel changes, verify:

```powershell
python -m pytest tests/unit/test_i18n.py -v
```

`tests/unit/test_i18n.py` automatically runs `validate_catalog(...)` across `"fr"`, `"zh"`, `"de"`, and `"ru"` (checking zero missing, empty, plural-form-count, or placeholder-mismatched keys) and `audit_untranslated_ui_literals()` (AST audit for bare English UI string literals).
