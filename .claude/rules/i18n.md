# Internationalization (i18n) Rules

All user-facing GUI text in SPECTROview supports live switching across **English** (`"en"`, default), **French** (`"fr"` / `Français`), **Simplified Chinese** (`"zh"` / `简体中文`), **German** (`"de"` / `Deutsch`), and **Russian** (`"ru"` / `Русский`) via `spectroview.i18n` and `spectroview/resources/i18n/<lang>.json`.

## Mandatory Conventions

- **Use `spectroview.i18n` on every UI / ViewModel user-facing string**:
  - Live-bound widgets: `bind_text`, `bind_plural_text`, `bind_tooltip`, `bind_placeholder`, `bind_title`, `bind_window_title`, `bind_tab_text`, `bind_header_labels`, `bind_combo_items`, `on_language_changed`.
  - Runtime notifications, dialogs, errors, and plot labels: `tr(...)` and `tr_plural(...)`.
  - Update all non-default translation catalogs (`fr.json`, `zh.json`, `de.json`, `ru.json`, sorted keys) in the **same commit** whenever English GUI strings are added or changed (`1` plural form for `zh`, `2` for `fr`/`de`, `3` Slavic forms for `ru`). Never add `if lang == "...":` branches in Views/ViewModels.
- **Canonical `Qt.UserRole` (`itemData`) on translated `QComboBox`**:
  - Bind display labels alongside canonical keys (`bind_combo_items`); read/restore using `combo_data_or_text()` and `set_combo_by_data_or_text()`.
- **`tr_plural` signature**: never pass `count=` as a keyword argument alongside positional `count`.
- **Escaped braces in formatted templates**: double literal braces when kwargs are present (e.g., `tr("{peak} peak position (cm$^{{-1}}$)", peak=peak)`).
- **`on_language_changed(owner, cb)`**: invokes `cb()` with **0 arguments** (weakref-held).
- **Never mutate `QLocale`** globally (`QLocale().decimalPoint()` must stay `"."`); Qt standard buttons localize via `QTranslator` (`qtbase_fr.qm`, `qtbase_zh_CN.qm`, `qtbase_de.qm`, `qtbase_ru.qm`).

## Non-Translatable Exclusions

Never translate Python/API symbols, `MGraph`/workspace schema keys, DataFrame columns, `PEAK_MODELS`, colormaps, Matplotlib `'Pan'`/`'Zoom'` keys, units, file extensions, scientific notation (`x0`, `FWHM`, `R²`), `CITATION_TEXT`, internal LLM prompt Markdown templates, or user data.

## Verification

```powershell
python -m pytest tests/unit/test_i18n.py -v
```

(`validate_catalog(...)` for `fr`, `zh`, `de`, `ru` + `audit_untranslated_ui_literals()` + live switching tests must pass cleanly.)
