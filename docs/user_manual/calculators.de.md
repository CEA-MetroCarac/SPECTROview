## **Schnellrechner** { #quick-calculation-tool }

Klicken Sie auf das Symbol **Calculator** in der Menüleiste (`Menu Bar`), um eine Sammlung praktischer Hilfsrechner zu öffnen:

![Werkzeug für Schnellberechnungen](../user_manual_images/menu_bar/ui_quick_calculation.png)

### **1. Laserspotgröße, Schärfentiefe und Laserleistungsdichte** { #1-laser-spot-size-depth-of-field-and-laser-power-density }

Dieses Werkzeug schätzt die theoretische, beugungsbegrenzte räumliche Auflösung Ihres optischen Aufbaus ab, einschließlich Spotgröße, Schärfentiefe und Laserleistungsdichte.

- **Spotgröße**: Berechnet als 1,22 × λ / NA (μm)
- **Schärfentiefe**: Berechnet als 4 × n × λ / NA<sup>2</sup> (μm)

### **2. Eindringtiefe** { #2-penetration-depth }

Dieses Werkzeug berechnet die theoretische optische Eindringtiefe eines Lasers in ein bestimmtes Material, abgeleitet aus dessen komplexem Brechungsindex (Extinktionskoeffizient).

- **Eindringtiefe (<i>d</i>)**: Berechnet als λ / (4πk) (nm)

### **3. Einheitenumrechner** { #3-unit-converter }

Ein schnelles Werkzeug zur Umrechnung zwischen verschiedenen gängigen spektroskopischen Einheiten, das eine durchgängige Konsistenz bei der Datenanalyse gewährleistet (z. B. Umrechnung der Wellenlänge in nm in Energie in eV oder Berechnung der Raman-Verschiebung in cm<sup>-1</sup> aus Anregungswellenlängen).
