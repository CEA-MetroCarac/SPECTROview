## **Инструмент для быстрых расчётов** { #quick-calculation-tool }

Нажмите на значок **Calculator** в строке меню (`Menu Bar`), чтобы открыть набор вспомогательных калькуляторов:

![Инструмент для быстрых расчётов](../user_manual_images/menu_bar/ui_quick_calculation.png)

### **1. Размер лазерного пятна, глубина резкости и плотность мощности лазера** { #1-laser-spot-size-depth-of-field-and-laser-power-density }

Этот инструмент оценивает теоретическое дифракционно-ограниченное пространственное разрешение вашей оптической установки, включая размер пятна, глубину резкости и плотность мощности лазера.

- **Размер пятна**: вычисляется как 1.22 × λ / NA (μm)
- **Глубина резкости**: вычисляется как 4 × n × λ / NA<sup>2</sup> (μm)

### **2. Глубина проникновения** { #2-penetration-depth }

Этот инструмент рассчитывает теоретическую оптическую глубину проникновения лазера в конкретный материал, определяемую по его комплексному показателю преломления (коэффициенту экстинкции).

- **Глубина проникновения (<i>d</i>)**: вычисляется как λ / (4πk) (nm)

### **3. Конвертер единиц** { #3-unit-converter }

Быстрая утилита для преобразования различных стандартных спектроскопических единиц измерения друг в друга, обеспечивающая полную согласованность данных в ходе анализа (например, перевод длины волны в nm в энергию в eV или расчёт рамановского сдвига в cm<sup>-1</sup> по длинам волн возбуждения).
