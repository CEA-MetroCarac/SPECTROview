## **快捷计算工具** { #quick-calculation-tool }

点击菜单栏 (`Menu Bar`) 中的 **Calculator** 图标，即可打开一组实用计算工具：

![快捷计算工具](../user_manual_images/menu_bar/ui_quick_calculation.png)

### **1. 激光光斑尺寸、景深与激光功率密度** { #1-laser-spot-size-depth-of-field-and-laser-power-density }

该工具可估算光学系统的理论衍射极限空间分辨率，包括光斑尺寸、景深和激光功率密度。

- **光斑尺寸**：按 1.22 × λ / NA 计算 (μm)
- **景深**：按 4 × n × λ / NA<sup>2</sup> 计算 (μm)

### **2. 穿透深度** { #2-penetration-depth }

该工具根据特定材料的复折射率（消光系数），计算激光在该材料中的理论光学穿透深度。

- **穿透深度 (<i>d</i>)**：按 λ / (4πk) 计算 (nm)

### **3. 单位换算器** { #3-unit-converter }

一款用于在各类标准光谱单位之间快速换算的实用工具，可确保数据分析过程中的单位一致性（例如将波长 (nm) 换算为能量 (eV)，或根据激发波长计算拉曼位移 (cm<sup>-1</sup>)）。
