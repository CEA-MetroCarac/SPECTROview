## **Dokumentation** { #documentation }

Die vollständige **Dokumentation** finden Sie unter [**CEA-MetroCarac.github.io/SPECTROview**](https://CEA-MetroCarac.github.io/SPECTROview/de/):

- **Für Anwender:** Ein umfassendes Benutzerhandbuch steht [online](https://cea-metrocarac.github.io/SPECTROview/de/user_manual/) zur Verfügung und kann auch direkt in der Anwendung aufgerufen werden.
- **Für Entwickler:** Ein ausführliches Entwicklerhandbuch finden Sie [hier](https://cea-metrocarac.github.io/SPECTROview/de/developer/).
- **Änderungsprotokoll:** Die neuesten Aktualisierungen und Versionshinweise können Sie [hier](https://cea-metrocarac.github.io/SPECTROview/de/changelog/) einsehen.

> Weitere Informationen finden Sie im [GitHub-Repository](https://github.com/CEA-MetroCarac/SPECTROview).
