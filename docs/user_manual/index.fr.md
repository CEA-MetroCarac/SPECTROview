## **Documentation**

La **documentation** complète est disponible sur [**CEA-MetroCarac.github.io/SPECTROview**](https://CEA-MetroCarac.github.io/SPECTROview/fr/) :

- **Pour les utilisateurs :** Un manuel utilisateur complet est accessible [en ligne](https://cea-metrocarac.github.io/SPECTROview/fr/user_manual/) et peut également être ouvert directement depuis l'application.
- **Pour les développeurs :** Un guide développeur détaillé est disponible [ici](https://cea-metrocarac.github.io/SPECTROview/fr/developer/).
- **Historique des versions :** Consultez les dernières mises à jour et notes de version [ici](https://cea-metrocarac.github.io/SPECTROview/fr/changelog/).

> Pour plus d'informations, consultez le [dépôt GitHub](https://github.com/CEA-MetroCarac/SPECTROview).
