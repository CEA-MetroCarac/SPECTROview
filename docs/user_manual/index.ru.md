## **Документация** { #documentation }

Полная **документация** доступна на сайте [**CEA-MetroCarac.github.io/SPECTROview**](https://CEA-MetroCarac.github.io/SPECTROview/ru/):

- **Для пользователей:** Полное руководство пользователя доступно [онлайн](https://cea-metrocarac.github.io/SPECTROview/ru/user_manual/), а также может быть открыто непосредственно в приложении.
- **Для разработчиков:** Подробное руководство разработчика доступно [здесь](https://cea-metrocarac.github.io/SPECTROview/ru/developer/).
- **История изменений:** Ознакомьтесь с последними обновлениями и примечаниями к выпускам [здесь](https://cea-metrocarac.github.io/SPECTROview/ru/changelog/).

> Для получения дополнительной информации посетите [репозиторий GitHub](https://github.com/CEA-MetroCarac/SPECTROview).
