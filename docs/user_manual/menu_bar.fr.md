## **Barre de menus**

### **1. Boutons de la barre de menus**

Une barre d'outils horizontale située en haut de l'application offre un accès rapide aux fonctionnalités essentielles :

| Bouton | Fonction |
|--------|----------|
| ![Open](../user_manual_images/menu_bar/open.png) | **Open** : Charge tout type de données pris en charge. L'application détecte automatiquement le format du fichier et bascule vers l'espace de travail adapté. |
| ![Save](../user_manual_images/menu_bar/save.png) | **Save** : Enregistre l'espace de travail actif dans un fichier dédié (`.maps`, `.spectra` ou `.graphs`), vous permettant d'interrompre et de reprendre votre session sans effort. |
| ![Clear](../user_manual_images/menu_bar/clear.png) | **Clear** : Réinitialise l'espace de travail actif (données chargées, visualiseurs, modèles de pics ajustés, résultats d'ajustement et état d'analyse multivariée) pour démarrer une nouvelle session. |
| ![Calculation](../user_manual_images/menu_bar/quick_calculation.png) | **Calculators** : Ouvre l'outil `Quick Calculators` (`Ctrl + Shift + C`, voir ci-dessous pour les détails). |
| ![AI Agent](../user_manual_images/menu_bar/ai_agent.png) | **SPECTROview AI Agent** : Ouvre le panneau de discussion IA (`Ctrl + Shift + A`) pour interroger, filtrer et tracer vos données en langage naturel. Voir la section « Agent IA ». |
| ![Settings](../user_manual_images/menu_bar/settings.png) | **Settings** : Ouvre le panneau `Settings Panel` (`Ctrl + Shift + S`, voir ci-dessous pour les détails). |
| ![Check for updates](../user_manual_images/menu_bar/check_update.png) | **Check for updates** : Vérifie manuellement sur la page GitHub Releases si une nouvelle version est disponible. |
| ![Theme](../user_manual_images/menu_bar/theme.png) | **Theme** : Ouvre un menu déroulant permettant de choisir le thème de l'interface — **Modern Dark**, **Modern Gray**, **Modern Light**, **Classic Dark** ou **Classic Light**. |
| ![User Manual](../user_manual_images/menu_bar/manual.png) | **User Manual** : Ouvre la documentation en ligne du manuel utilisateur dans votre navigateur (`Ctrl + Shift + M`). |
| ![GitHub](../user_manual_images/menu_bar/github.png) | **GitHub** : Ouvre le dépôt GitHub de SPECTROview dans votre navigateur. |
| ![About](../user_manual_images/menu_bar/about.png) | **About** : Affiche les informations de version, la licence et les détails relatifs à l'application **SPECTROview**. |

> Une **étiquette de version** grisée (par exemple `v26.29.0`) apparaît tout à droite de la barre d'outils — cliquez dessus pour consulter les dernières notes de version.

### **4. Raccourcis clavier**

Vous pouvez accéder rapidement aux outils depuis n'importe quel écran de l'application grâce aux raccourcis clavier suivants :

- `Ctrl + Shift + A` : Ouvrir l'agent conversationnel IA
- `Ctrl + Shift + S` : Ouvrir le panneau des paramètres
- `Ctrl + Shift + M` : Ouvrir le manuel utilisateur
- `Ctrl + Shift + C` : Ouvrir les calculateurs rapides
