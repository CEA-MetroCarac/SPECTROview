## **Строка меню** { #menu-bar }

### **1. Кнопки строки меню** { #1-menu-bar-buttons }

Горизонтальная панель инструментов в верхней части окна приложения обеспечивает быстрый доступ к основным функциям:

| Кнопка | Функция |
|--------|---------|
| ![Открыть](../user_manual_images/menu_bar/open.png) | **Открыть** (Open): Загружает данные любого поддерживаемого типа. Приложение автоматически определяет формат файла и переключается в соответствующую рабочую область. |
| ![Сохранить](../user_manual_images/menu_bar/save.png) | **Сохранить** (Save): Сохраняет активную рабочую область в отдельный файл (`.maps`, `.spectra` или `.graphs`), позволяя легко приостанавливать и возобновлять работу. |
| ![Очистить](../user_manual_images/menu_bar/clear.png) | **Clear**: Очищает текущую активную рабочую область, сбрасывая загруженные данные, окна просмотра, модели аппроксимации пиков, результаты аппроксимации и состояние многомерного анализа для начала новой сессии. |
| ![Расчёт](../user_manual_images/menu_bar/quick_calculation.png) | **Calculators**: Открывает инструмент `Quick Calculators` (`Ctrl + Shift + C`, подробнее см. ниже). |
| ![ИИ-агент](../user_manual_images/menu_bar/ai_agent.png) | **ИИ-ассистент SPECTROview** (SPECTROview AI Agent): Открывает панель ИИ-чат-агента (`Ctrl + Shift + A`) для выполнения запросов, фильтрации и построения графиков на естественном языке. См. раздел «ИИ-чат-агент». |
| ![Настройки](../user_manual_images/menu_bar/settings.png) | **Настройки** (Settings): Открывает панель `Settings Panel` (`Ctrl + Shift + S`, подробнее см. ниже). |
| ![Проверить обновления](../user_manual_images/menu_bar/check_update.png) | **Проверить обновления** (Check for updates): Вручную проверяет наличие более новой версии на странице GitHub Releases. |
| ![Тема](../user_manual_images/menu_bar/theme.png) | **Theme**: Открывает выпадающий список для выбора темы интерфейса — **Современная тёмная** (Modern Dark), **Современная серая** (Modern Gray), **Современная светлая** (Modern Light), **Классическая тёмная** (Classic Dark) или **Классическая светлая** (Classic Light). |
| ![Руководство пользователя](../user_manual_images/menu_bar/manual.png) | **User Manual**: Открывает онлайн-документацию руководства пользователя в браузере (`Ctrl + Shift + M`). |
| ![GitHub](../user_manual_images/menu_bar/github.png) | **GitHub**: Открывает репозиторий SPECTROview на GitHub в браузере. |
| ![О программе](../user_manual_images/menu_bar/about.png) | **О программе** (About): Отображает сведения о версии, лицензии и подробную информацию о приложении **SPECTROview**. |

> В правой части панели инструментов отображается неактивная серая **метка версии** (например, `v26.29.0`) — нажмите на неё, чтобы просмотреть список последних изменений.

### **4. Горячие клавиши** { #4-keyboard-shortcuts }

Вы можете быстро открывать эти инструменты из любого места приложения с помощью следующих горячих клавиш:

- `Ctrl + Shift + A`: Открыть ИИ-чат-агент
- `Ctrl + Shift + S`: Открыть панель настроек
- `Ctrl + Shift + M`: Открыть руководство пользователя
- `Ctrl + Shift + C`: Открыть калькуляторы
