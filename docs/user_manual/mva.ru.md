## **Многомерный анализ (MVA)** { #multivariate-analysis-mva }

В **SPECTROview** встроены инструменты многомерного анализа (MVA), удобно доступные на отдельной вкладке **MVA** как в рабочей области **Спектры** (`Spectra`), так и в рабочей области **Карты** (`Maps`).

> **Примечание**: для выполнения алгоритмов MVA требуется минимум 2 активных спектра.

### **1. Поддерживаемые алгоритмы** { #1-supported-algorithms }

#### **1.1. Метод главных компонент (PCA)** { #11-principal-component-analysis-pca }

Статистическая процедура, выполняющая ортогональное преобразование и снижение размерности сложных наборов спектральных данных для выявления наиболее значимых закономерностей дисперсии. Реализация основана на сингулярном разложении матриц (SVD).

  - **Параметры**:
    - **Компоненты** (Components, 2–50): количество сохраняемых главных компонент.
    - **Центрирование по среднему** (Mean centering, вкл./выкл.): определяет, нужно ли вычитать средний спектр перед анализом. По умолчанию: вкл.
  - **Доступные визуализации**: сводная панель, графики собственных значений (объяснённая дисперсия), нагрузки главных компонент, 2D пространственная тепловая карта компоненты, графики факторов и графики невязок (ошибки восстановления).

#### **1.2. Неотрицательная матричная факторизация (NMF)** { #12-non-negative-matrix-factorization-nmf }

Мощный алгоритм разложения, который разделяет спектральные данные на отдельные аддитивные неотрицательные компоненты, часто соответствующие чистым химическим компонентам (*endmembers*).

  - **Параметры**:
    - **Компоненты** (2–50): количество извлекаемых неотрицательных компонент.
    - **Макс. итераций** (Max Iterations, 50–5000): максимальное число итераций обновления.
    - **Допуск** (Tolerance): порог сходимости для досрочной остановки.
    - **Зерно (seed)** (Random Seed): начальное значение для воспроизводимости результатов.
  - **Доступные визуализации**: сводная панель, нагрузки компонент, 2D пространственная тепловая карта компоненты, графики факторов и графики невязок (ошибки восстановления).

> **Почему в NMF нет графика собственных значений?**  
> В отличие от PCA, который строго упорядочивает ортогональные компоненты по максимуму объясняемой ими дисперсии, метод NMF находит неортогональные аддитивные компоненты (*endmembers*), смешивающиеся друг с другом. Поскольку компоненты NMF не являются ортогональными и не упорядочены последовательно по дисперсии, для каждой отдельной компоненты невозможно вычислить изолированный процент «объяснённой дисперсии». Для оценки модели NMF используйте график **Невязки** (Residuals), чтобы проконтролировать качество восстановления данных, а также **Нагрузки (Loadings)**, чтобы убедиться, что выделенные компоненты соответствуют физически осмысленным спектрам.

### **2. Пользовательский интерфейс** { #2-user-interface }

Вкладка MVA имеет **двухпанельную компоновку**:

#### **2.1. Левая панель — элементы управления** { #21-left-panel-controls }

- **Выбор метода**: выберите `PCA` или `NMF` с помощью переключателей.
- **Управление параметрами**: все настраиваемые параметры доступны в виде интерактивных элементов графического интерфейса (счётчиков, флажков). Отображаются только параметры, относящиеся к выбранному методу.
- **Кнопка запуска**: нажмите ▶ **Запустить анализ** (Run Analysis), чтобы выполнить расчёт с текущими параметрами.
- **Экспорт**: отправьте результаты (факторы) в рабочую область **Графики** (`Graphs`) для дальнейшего анализа.

#### **2.2. Правая панель — вкладки графиков** { #22-right-panel-tabbed-plots }

Результаты отображаются на нескольких вкладках, каждая из которых оснащена собственной интерактивной панелью инструментов `matplotlib` (масштабирование, панорамирование, сохранение):

| Вкладка | PCA | NMF | Описание |
|---------|-----|-----|----------|
| **Сводка** (Summary) | ✅ | ✅ | Комбинированная обзорная панель, одновременно отображающая собственные значения, нагрузки и факторы |
| **График собственных значений** (Scree Plot) | ✅ | - | Столбчатая диаграмма объяснённой дисперсии по компонентам с кривой накопленной дисперсии |
| **Нагрузки (Loadings)** | ✅ | ✅ | Спектральные профили нагрузок, наложенные на ось волновых чисел |
| **Тепловая карта** (Heatmap) | ✅ | ✅ | Пространственная 2D-карта факторов для выбранной компоненты *(если в названиях спектров присутствуют пространственные координаты `(x, y)`)* |
| **Факторы (Scores)** | ✅ | ✅ | 2D-диаграмма рассеяния с возможностью выбора компонент для осей X и Y |
| **Невязки** | ✅ | ✅ | Ошибка восстановления для каждого спектра для оценки качества модели |

### **3. Советы** { #3-tips }

- Используйте **График собственных значений**, чтобы определить оптимальное число компонент (ищите характерный излом — «локоть» — на кривой накопленной дисперсии).
- График **Нагрузки (Loadings)** показывает, какие спектральные признаки вносят наибольший вклад в каждую компоненту.
- Вкладка **Тепловая карта** визуализирует, в каких областях с пространственными координатами карты `(x, y)` концентрируется значение фактора выбранной компоненты.
- График **Факторы (Scores)** выявляет группировки (кластеры) и выбросы в вашем наборе данных.
- Вкладка **Невязки** помогает выявить спектры, которые плохо восстанавливаются моделью.
- На каждой вкладке с графиками имеется **панель инструментов `matplotlib`** для масштабирования, панорамирования и сохранения рисунков.
