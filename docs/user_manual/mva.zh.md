## **多元分析 (MVA)** { #multivariate-analysis-mva }

**SPECTROview** 内置了多元分析 (MVA) 工具，可通过**光谱** (`Spectra`) 和**二维图谱** (`Maps`) 工作区中的专用 **MVA** 标签页轻松访问。

> **注意**：MVA 算法至少需要 2 条激活光谱才能运行。

### **1. 支持的算法** { #1-supported-algorithms }

#### **1.1. 主成分分析 (PCA)** { #11-principal-component-analysis-pca }

一种通过正交变换对复杂光谱数据集进行降维的统计方法，能够揭示数据中最显著的方差变化模式。该实现基于奇异值分解 (SVD)。

- **参数**：
    - **主成分/组分数** (Components, 2–50)：要保留的主成分数量。
    - **均值中心化** (Mean centering，开启/关闭)：是否在分析前减去平均光谱。默认：开启。
- **可用可视化图表**：摘要仪表盘、碎石图（方差解释率）、主成分载荷图、二维空间组分热图、得分图以及残差重构误差图。

#### **1.2. 非负矩阵分解 (NMF)** { #12-non-negative-matrix-factorization-nmf }

一种强大的矩阵分解算法，可将光谱数据分解为互不相同、可加的非负组分，通常对应于纯化学组分（端元，endmembers）。

- **参数**：
    - **主成分/组分数** (2–50)：要提取的非负组分数量。
    - **最大迭代次数** (Max Iterations, 50–5000)：最大更新迭代次数。
    - **容差** (Tolerance)：用于提前停止迭代的收敛阈值。
    - **随机种子** (Random Seed)：用于确保结果可复现。
- **可用可视化图表**：摘要仪表盘、组分载荷图、二维空间组分热图、得分图以及残差重构误差图。

> **为什么 NMF 没有碎石图？**  
> 与严格按最大方差解释率对正交主成分进行排序的 PCA 不同，NMF 提取的是相互混合的非正交、可加组分（端元）。由于 NMF 组分既不正交，也不按方差大小顺序排列，因此无法为每个单独组分计算孤立的“方差解释率”百分比。要评估 NMF 模型，请通过**残差** (Residuals) 图评估重构质量，并通过**载荷 (Loadings)** 确认提取的组分是否对应于具有物理意义的光谱。

### **2. 用户界面** { #2-user-interface }

MVA 标签页采用**左右分栏布局**：

#### **2.1. 左侧面板 — 控制区** { #21-left-panel-controls }

- **方法选择**：使用单选按钮在 `PCA` 与 `NMF` 之间切换。
- **参数控制**：所有可调参数均以交互式图形界面控件（数值微调框、复选框）呈现，且仅显示当前所选方法对应的相关参数。
- **运行按钮**：点击 ▶ **运行分析** (Run Analysis)，使用当前参数执行分析。
- **导出**：将结果（得分）发送至**图表** (`Graphs`) 工作区以进行进一步分析。

#### **2.2. 右侧面板 — 分页图表区** { #22-right-panel-tabbed-plots }

分析结果在多个标签页中展示，每个标签页均配有独立的交互式 `matplotlib` 工具栏（支持缩放、平移和保存）：

| 标签页 | PCA | NMF | 说明 |
|--------|-----|-----|------|
| **摘要** (Summary) | ✅ | ✅ | 组合式仪表盘，同屏展示碎石图、载荷和得分图 |
| **碎石图** (Scree Plot) | ✅ | - | 各主成分方差解释率的柱状图及累计贡献率曲线 |
| **载荷 (Loadings)** | ✅ | ✅ | 叠加显示在波数轴上的光谱载荷轮廓曲线 |
| **热图** (Heatmap) | ✅ | ✅ | 可选组分的二维空间得分分布图 *(当光谱名称中包含空间 `(x, y)` 坐标时可用)* |
| **得分 (Scores)** | ✅ | ✅ | 可选择 X/Y 组分轴的二维散点图 |
| **残差** | ✅ | ✅ | 逐条光谱的重构误差，用于评估模型质量 |

### **3. 使用技巧** { #3-tips }

- 使用**碎石图**确定最佳主成分数量（观察累计方差解释率曲线中的“拐点”）。
- **载荷 (Loadings)** 图可展示哪些光谱特征对每个组分贡献最大。
- **热图**标签页可直观呈现所选组分得分在二维空间 `(x, y)` 分布图坐标中的富集位置。
- **得分 (Scores)** 图有助于发现数据集中的聚类分组与异常样本（离群点）。
- **残差**标签页有助于识别模型重构效果较差的光谱。
- 每个图表标签页均配有 **`matplotlib` 工具栏**，支持缩放、平移和保存图像。
