## **Сохранение и загрузка рабочей области** { #save-load-workspace }

**SPECTROview** использует специализированные собственные форматы файлов, позволяющие без труда приостанавливать, сохранять и возобновлять сеансы анализа данных, не теряя ни настроек, ни результатов аппроксимации.

### **1. Сохранение работы** { #1-saving-your-work }

Чтобы сохранить текущий прогресс, нажмите кнопку **Сохранить** (Save) на главной панели инструментов приложения:

<div align="center">
  <img src="../user_manual_images/Save_Load/save_load_clear.png" alt="Кнопки «Сохранить», «Загрузить» и «Очистить»" width="120"><br>
</div>

Приложение задаёт определённое расширение файла в зависимости от текущей активной рабочей области:

| Активная рабочая область | Собственное расширение | Сохраняемое содержимое |
|-----------|-----------|----------|
| **Спектры** (Spectra) | `.spectra` | Все загруженные 1D-спектры, пользовательские настройки базовой линии (`baseline`), математические модели аппроксимации и сводные результаты аппроксимации. |
| **Карты** (Maps) | `.maps` | Исходные данные 2D-карт и карт пластин, метаданные прибора, все связанные спектры и все поточечные результаты аппроксимации. |
| **Графики** (Graphs) | `.graphs` | Все загруженные математические наборы данных, индивидуальные настройки графиков и нанесённые аннотации. |

### **2. Загрузка работы** { #2-loading-your-work }

Чтобы возобновить предыдущий сеанс, просто нажмите кнопку **Открыть** (Open) на главной панели инструментов и выберите любой ранее сохранённый файл `.spectra`, `.maps` или `.graphs`. **SPECTROview** автоматически определит формат файла, в точности восстановит ваш набор данных в том виде, в котором вы его оставили, и мгновенно откроет вкладку соответствующей рабочей области.
