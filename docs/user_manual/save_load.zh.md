## **保存与加载工作区** { #save-load-workspace }

**SPECTROview** 采用专用的原生文件格式，让您能够无缝暂停、保存并恢复数据分析会话，而不会丢失任何配置或拟合结果。

### **1. 保存您的工作** { #1-saving-your-work }

要保存当前进度，请点击应用程序主工具栏中的 **保存** (Save) 按钮：

<div align="center">
  <img src="../user_manual_images/Save_Load/save_load_clear.png" alt="保存、加载与清空按钮" width="120"><br>
</div>

应用程序将根据当前活动的工作区生成对应的文件扩展名：

| 活动工作区 | 原生扩展名 | 存储内容 |
|-----------|-----------|----------|
| **光谱** (Spectra) | `.spectra` | 所有已加载的一维光谱、自定义基线 (`baseline`) 配置、数学拟合模型以及汇总拟合结果。 |
| **二维图谱** (Maps) | `.maps` | 原始二维/晶圆图谱数据、仪器元数据、所有关联光谱以及全部逐点拟合结果。 |
| **图表** (Graphs) | `.graphs` | 所有已加载的数学数据集、自定义图表配置以及已绘制的标注。 |

### **2. 加载您的工作** { #2-loading-your-work }

要恢复先前的分析会话，只需点击主工具栏中的 **打开** (Open) 按钮，然后选择此前保存的任意 `.spectra`、`.maps` 或 `.graphs` 文件。**SPECTROview** 将自动识别文件格式，精确还原您上次离开时的数据集状态，并立即打开对应的工作区标签页。
