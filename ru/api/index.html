    API¶

    Python API SPECTROview позволяет автоматизировать рабочие процессы и программно взаимодействовать с основными движками обработки спектроскопических данных SPECTROview. Он полностью отделён от графического интерфейса Qt (QApplication не требуется), что делает его удобным для использования в Jupyter-ноутбуках, пакетных скриптах и CI-конвейерах.

    Все модули доступны через пакет spectroview.api.

    Модули API¶

    • spectroview.api.workspace — SpectraWorkspace / MapsWorkspace: сессии с сохранением состояния, объединяющие в одном месте загрузку, предобработку, аппроксимацию, сбор результатов, а также сохранение и повторную загрузку. Записываемые и читаемые ими файлы используют точно такой же формат, что и функция Сохранить проект (Save work) самого графического интерфейса — рабочая область, полностью созданная из скрипта, открывается напрямую в графическом интерфейсе, и наоборот.
    • spectroview.api.io — модули чтения файлов (WDF, SPC, L6S, L6M, NGS, NGC, CSV, TXT, DAT), импорт наборов данных, экспорт результатов и конвертер карт Renishaw без графического интерфейса.
    • spectroview.api.preprocessing — функции без сохранения состояния на уровне массивов для вычитания базовой линии, обрезки и нормировки.
    • spectroview.api.fitting — интерфейс к векторизованному движку пакетной аппроксимации (VBF): построение моделей, пакетная аппроксимация и CRUD-операции с шаблонами моделей аппроксимации.
    • spectroview.api.analysis — многомерный анализ: PCA и NMF.
    • spectroview.api.graphs — графики публикационного качества, с точностью до пикселя воспроизводящие отрисовку в графическом интерфейсе для всех 9 поддерживаемых стилей графиков, а также CRUD-операции с шаблонами графиков.
    • spectroview.api.calculators — физические калькуляторы для оптики и преобразования единиц измерения.
    • spectroview.api.settings — доступ на чтение и запись без графического интерфейса к постоянной конфигурации (параметры аппроксимации по умолчанию, папка моделей, последний использованный каталог, язык интерфейса через get_language() / set_language()).
    • spectroview.api.exceptions — иерархия исключений SpectroviewError, генерируемых во всём пакете (LoadError, FitModelError, FitError, WorkspaceError, TemplateError).

    Изучение API¶

    • Рабочая область «Спектры»: загрузка дискретных спектров, их предобработка и запуск движка пакетной аппроксимации — как в режиме с сохранением состояния через SpectraWorkspace, так и через низкоуровневые операции над массивами.
    • Рабочая область «Карты» и 2D-анализ: загрузка гиперспектральных карт и карт пластин, аппроксимация каждого пикселя, построение тепловых карт и линейных профилей, а также выполнение анализа PCA/NMF.
    • Визуализация данных («Графики»): воспроизведение в скриптах штатных графиков SPECTROview для всех стилей построения, а также работа с переиспользуемыми шаблонами графиков.
    • Калькуляторы: программные конвертеры для оптических величин и спектроскопических единиц измерения.
    • Расширение SPECTROview: реальные точки расширения на основе файлов (пользовательские методы базовой линии, папки с шаблонами моделей аппроксимации и графиков) — фреймворка плагинов здесь нет, и на этой странице объясняется, что доступно вместо него.

    Обработка ошибок¶

    Каждая функция в spectroview.api при сбое генерирует подкласс spectroview.api.exceptions.SpectroviewError — никогда не исходное исключение KeyError/ValueError из нижележащего слоя модели и никогда не диалоговое окно Qt (которое привело бы к зависанию скрипта без графического интерфейса). Перехватывайте либо общее исключение SpectroviewError, либо конкретный подтип (LoadError, FitModelError, FitError, WorkspaceError, TemplateError):

    from spectroview.api import io
from spectroview.api.exceptions import LoadError

try:
    data = io.load_spectra("missing_file.wdf")
except LoadError as e:
    print(f"Could not load spectra: {e}")
