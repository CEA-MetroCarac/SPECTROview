    Многомерный анализ (MVA) данных рамановской спектроскопии¶

    В этом документе представлен технический обзор инструментов многомерного анализа (MVA), реализованных в SPECTROview.

    Архитектура¶

    Модуль MVA следует архитектурному паттерну MVVM (Model-View-ViewModel):

    • Model (spectroview/model/analysis/m_mva.py): содержит математическую базу методов MVA, в частности метод главных компонент (PCA) и неотрицательную матричную факторизацию (NMF). Использует стандартные численные библиотеки (numpy, scipy) без необходимости в дополнительных зависимостях вроде scikit-learn.
    • ViewModel (spectroview/viewmodel/analysis/vm_mva.py): оркестрирует поток данных. Извлекает предобработанные данные из активных спектров, вызывает Model для выполнения вычислений, кэширует результаты и рассчитывает ошибки восстановления для каждого спектра.
    • View (spectroview/view/components/lower_tabs/: v_mva.py, v_mva_plots.py): предоставляет пользовательский интерфейс с панелью вкладок графиков (Сводка (Summary), График собственных значений (Scree Plot), Нагрузки (Loadings), Тепловая карта (Heatmap), Факторы (Scores), Невязки (Residuals)), интерактивными элементами управления параметрами и панелями инструментов навигации matplotlib для каждого графика.

    Реализация алгоритмов¶

    Реализация PCA в SPECTROview основана на сингулярном разложении матриц (SVD) для данных, центрированных по среднему.

    Расширенные возможности визуализации¶

    SPECTROview предлагает многофункциональный интерфейс с вкладками графиков для наглядного представления результатов:

    • Сводка: сводная панель 2×2, отображающая график собственных значений (только PCA), первые 3 нагрузки и основные проекции диаграмм рассеяния факторов
    • График собственных значений (только PCA): столбчатая диаграмма индивидуальной дисперсии и кривая накопленной дисперсии
    • Нагрузки (Loadings): наложенные спектральные профили нагрузок с заливкой области под кривой для лучшей читаемости
    • Тепловая карта: пространственная 2D-карта факторов выбранной компоненты, если названия спектров содержат координаты (x, y)
    • Факторы (Scores): 2D-диаграмма рассеяния с интерактивным выбором осей
    • Невязки: ошибка восстановления по каждому спектру для оценки качества модели

    Реализованные методы¶

    1. Метод главных компонент (PCA)¶

    PCA — это метод снижения размерности, который преобразует спектры в новую систему координат так, чтобы наибольшая дисперсия при любой проекции данных приходилась на первую координату (первую главную компоненту).

    • Детали реализации: реализован с помощью сингулярного разложения (numpy.linalg.svd) для данных с опциональным центрированием по среднему.
    • Параметры:
    • Компоненты (Components): число сохраняемых главных компонент (2–50).
    • Центрирование по среднему (Mean centering): определяет, следует ли вычитать средний спектр перед SVD (по умолчанию: вкл.). Это стандартная практика для спектрального PCA.
    • Визуализации:
    • Сводка: обзорная панель 2×2, объединяющая график собственных значений, нагрузки и основные пары факторов.
    • График собственных значений: отображает процент дисперсии, объяснённой каждой главной компонентой, и накопленную дисперсию.
    • Нагрузки (Loadings): визуализирует спектральный вклад каждой главной компоненты с указанием процента объяснённой дисперсии в легенде.
    • Тепловая карта: пространственный 2D-график факторов для выбранной компоненты, если в названиях спектров закодированы координаты (x, y).
    • Факторы (Scores): строит 2D-диаграмму рассеяния спектров в проекции на главные компоненты с интерактивным выбором осей.
    • Невязки: L2-ошибка восстановления по каждому спектру для оценки качества модели.

    2. Неотрицательная матричная факторизация (NMF)¶

    NMF факторизует матрицу данных в две неотрицательные матрицы (обычно W и H). Этот подход особенно полезен для спектроскопических данных, так как даёт аддитивные неотрицательные компоненты, которые зачастую соответствуют физическим чистым спектральным компонентам (endmembers).

    • Детали реализации: использует правила мультипликативного обновления Ли и Сынга (Lee & Seung), итеративно обновляя матрицы для минимизации нормы Фробениуса ошибки восстановления.
    • Параметры:
    • Компоненты: число неотрицательных компонент (или чистых спектральных составляющих), извлекаемых из набора данных.
    • Макс. итераций (Max Iterations): максимальное число итераций мультипликативного обновления, разрешённое алгоритму. Если сходимость не достигнута в пределах этого лимита, алгоритм останавливается.
    • Допуск (Tolerance): порог сходимости. Алгоритм завершается досрочно, если относительное изменение ошибки восстановления между последовательными итерациями опускается ниже этого значения.
    • Зерно (seed) (Random Seed): начальное значение для генератора случайных чисел, используемого при инициализации матриц. Фиксированный seed обеспечивает воспроизводимость результатов NMF от запуска к запуску (по умолчанию: 42).
    • Визуализации:
    • Сводка: обзорная панель нагрузок и основных проекций факторов NMF.
    • Нагрузки (Loadings): отображает неотрицательные спектральные компоненты (чистые составляющие).
    • Тепловая карта: пространственная 2D-карта распределения (содержания) для выбранной компоненты NMF при наличии координат (x, y) в названиях спектров.
    • Факторы (Scores): строит 2D-диаграмму рассеяния концентраций/вкладов этих компонент по всему набору данных.
    • Невязки: L2-ошибка восстановления по каждому спектру.

    Почему в NMF нет графика собственных значений?
    В отличие от PCA, который строго упорядочивает ортогональные компоненты по максимуму объясняемой ими дисперсии, метод NMF находит неортогональные аддитивные компоненты (чистые спектральные составляющие — endmembers), которые смешиваются друг с другом. Поскольку компоненты NMF не являются ортогональными и не упорядочены последовательно по дисперсии, для каждой отдельной компоненты невозможно вычислить изолированный процент «объяснённой дисперсии». Для оценки модели NMF опирайтесь на график Невязки, чтобы контролировать качество восстановления, и на Нагрузки (Loadings), чтобы убедиться, что выделенные компоненты соответствуют физически осмысленным спектрам.

    Пользовательский интерфейс¶

    Вкладка MVA имеет двухпанельную компоновку:

    Левая панель (элементы управления)¶

    • Выбор метода: переключатели (радиокнопки) для выбора между PCA и NMF.
    • Группы параметров: отдельные блоки параметров для PCA и NMF, отображающие только настройки, относящиеся к выбранному методу.
    • Кнопка запуска (Запустить анализ (Run Analysis)): выполняет анализ.
    • Секция экспорта: отправляет факторы в рабочую область Graphs.

    Правая панель (вкладки с графиками)¶

    Каждый тип графика занимает отдельную вкладку внутри QTabWidget:

    • Сводка: комбинированная обзорная сетка (график собственных значений [PCA], первые 3 нагрузки и основные проекции диаграмм рассеяния факторов).
    • График собственных значений (только PCA): дисперсия, объяснённая каждой компонентой.
    • Нагрузки (Loadings): спектральные профили нагрузок.
    • Тепловая карта: пространственная 2D-карта факторов выбранной компоненты (требует координат (x, y) в названиях спектров).
    • Факторы (Scores): интерактивная 2D-диаграмма рассеяния с выбором осей.
    • Невязки: качество восстановления по каждому спектру.

    Каждая вкладка оснащена панелью инструментов NavigationToolbar из matplotlib для масштабирования, панорамирования и сохранения графиков.

    Конвейер данных¶

    1. Выбор данных: MVA работает исключительно с активными (отмеченными флажком) спектрами в рабочей области SPECTROview.
    2. Предобработка: VMMVA считывает данные напрямую из SpectraStore (md.Y при наличии предобработки, с возвратом к md.Y0 для необработанных данных), то есть обрабатывает данные, уже прошедшие настроенные пользователем этапы предобработки (вычитание baseline, обрезку диапазона, X-коррекцию).
    3. Интерполяция: если выбранные спектры имеют различные оси волновых чисел, они автоматически интерполируются на общую сетку (сетку первого активного спектра) для формирования согласованной матрицы данных.
    4. Экспорт: результаты (факторы для PCA, матрица W для NMF) могут быть экспортированы напрямую в рабочую область Graphs для дальнейшей визуализации и сравнения.

    Цитирование и литература¶

    Если эти функции используются для получения результатов, предназначенных для публикации, просим пользователей ссылаться на соответствующие научные работы по реализованным алгоритмам:

    [1] Алгоритм PCA: Wold, S., Esbensen, K., and Geladi, P., "Principal component analysis." Chemometrics and intelligent laboratory systems 2.1-3 (1987): 37-52.

    [2] Алгоритм NMF: Lee, Daniel D., and H. Sebastian Seung, "Learning the parts of objects by non-negative matrix factorization." Nature 401.6755 (1999): 788-791.
